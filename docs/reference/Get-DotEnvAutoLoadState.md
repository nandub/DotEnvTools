# Get-DotEnvAutoLoadState

## SYNOPSIS
Gets DotEnvTools auto-load state.

## SYNTAX

```
Get-DotEnvAutoLoadState [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION
Returns current auto-load settings and tracked file information.

## EXAMPLES

### EXAMPLE 1
```
Get-DotEnvAutoLoadState
```
